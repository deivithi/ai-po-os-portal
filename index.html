    Leitura recomendada

    Sequencia ideal para ganhar contexto rapido

    1. Comece pela Trilha para montar o plano com o seu ritmo real.
    2. Abra Jornada para consolidar o metodo da semana.
    3. Abra Prompts para estruturar melhor o comando dos modelos.
    4. Use Matriz para comparar modelos e criterios.
    5. Estude RAG para dominar contexto, memoria e citacao.
    6. Abra Workflows para ver aplicacao operacional.
    7. Suba para Senior para estudar evals, memoria, agents e producao.
    8. Abra Progresso para marcar checkpoints e replanejar o restante.
    9. Feche no Roadmap para revisar maturidade e proximo passo.
